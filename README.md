# MH Horizon

Static gateway website for the MH Horizon ecosystem.

## Live hub routes

- Game Hub: https://gamehub.mhhorizons.com/
- Informative Hub: https://informativehub.mhhorizons.com/
- Recipify Hub: https://recipify.mhhorizons.com/
- FocusForge: https://focusforge.mhhorizon.com/
- MH Tools: https://tools.mhhorizons.com/
- PythonLab: https://pythonlab.mhhorizons.com/
- Quizora: https://quizora.mhhorizons.com/

## GitHub Pages

The site is ready to publish from the repository root. `CNAME` is set to `mhhorizons.com`, and `.nojekyll` keeps GitHub Pages from processing static files.

No build step is required.
